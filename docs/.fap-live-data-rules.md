# Fund AI Pro live data rules

## Portfolio
- On trading days during active market sessions, portfolio cards MUST prefer the current cross-validated intraday estimate.
- Cached NAV is not a substitute for live valuation during an active trading session.
- Refresh the portfolio no more frequently than every 3 minutes by default.
- Cross-source validation failure must not be replaced with simulated or guessed values. Show unavailable state instead.
- After close, keep the same-day last reliable intraday estimate until official NAV is actually published; then immediately prefer official NAV.
- On weekends/pre-open, use the latest reliable official trading-day snapshot.

## Sector watch
- Render the user's saved sectors immediately from local state.
- Sector percentage/price can render independently from money-flow fields.
- Money-flow fields may load later and must never block the sector card from rendering.
- Search and quick-add must not fabricate a sector result when no reliable match exists.
- A missing flow field is displayed as unavailable, not zero.

## General loading behavior
- Hydration restores local UI state immediately.
- Background network refresh must never clear an already-rendered valid module.
- Each module is independently refreshable; unrelated network calls must not gate its first paint.
