# Fund AI Pro · 最终验收清单 / 项目完成路线图

> **最终目标：** 不再改首页信息架构，只把已经确定的产品结构逐项做实、做稳、做可验证。
>
> 首页永久固定为：**总收益 → 今日市场评分/今日评估 → 我的持仓（组合体检 + 波段/趋势/做T）→ 自选板块（板块基金池）→ 操作建议 → 最新资讯（5条）→ 全部服务**。
>
> **完成定义：** 每一个项目必须满足“有真实数据/明确无数据状态 + 可操作入口 + 自动化测试 + Production 验证”后才能打勾。全部项目完成并通过最终验收后封版，不再追加新功能。
>
> **发布纪律：** 代码集中收敛后再做一次 Production 部署验证，避免反复触发 Vercel Hobby build rate limit。
