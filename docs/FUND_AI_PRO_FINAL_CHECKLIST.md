# Fund AI Pro · 最终验收清单

> 规则：只处理本清单范围内的问题。发现 Bug 立即记录、修复、验证；不在验收期间追加无关功能。

## 01 · 生产稳定性
- [ ] Production 使用最新 `main`
- [ ] 首页连续打开/刷新稳定，无白屏、500、随机 Connection aborted
- [ ] `/__server` 无 `Server function info not found`
- [ ] 关键 API 无持续 4xx/5xx
- [ ] GitHub → Vercel 自动部署链唯一且稳定

## 02 · 数据正确性
- [ ] 开盘：盘中实时估值
- [ ] 午间：冻结上午最后可靠估值
- [ ] 下午：恢复实时估值
- [ ] 收盘：等待官方净值
- [ ] 官方净值发布后自动切换
- [ ] 周末/休市：显示最近交易日可靠数据
- [ ] 旧数据不得冒充今日官方净值
- [ ] 多源失败时保留最后可靠数据，不生成模拟数据
- [ ] 新闻保留真实发布时间，不用抓取时间冒充发布时间

## 03 · 添加基金与持仓
- [ ] 输入代码后可识别基金
- [ ] 份额 × 成本价立即本地计算成本
- [ ] 保存后基金名称/代码/成本/份额立即存在
- [ ] 网络失败不能清空已保存持仓
- [ ] 盘中显示可靠估值与当日收益
- [ ] 收盘切官方净值
- [ ] 多只基金形成组合总览
- [ ] 组合收益与单基金收益完全分开
- [ ] 今日/本周/本月/今年/以来口径明确

## 04 · 页面与 UI
- [ ] 浅色白底专业风格
- [ ] 淡蓝 Liquid Glass，不使用黑色主题
- [ ] 首屏 3 秒看到组合核心数据
- [ ] 重要信息前置，详情向下滚动
- [ ] 不以大量加载中/空白占位阻塞用户
- [ ] 单基金卡信息精简，深度指标可展开
- [ ] 小屏手机不溢出、不挤压

## 05 · 性能与容错
- [ ] 首屏先恢复本地可靠数据，再后台更新
- [ ] 刷新调度不重复触发
- [ ] 基金请求有并发上限
- [ ] 新闻不在非必要页面抢占首屏
- [ ] 玻璃模糊在移动端保持轻量
- [ ] 所有数值格式化有 null/NaN 防护
- [ ] 单个数据源失败不拖垮整页
